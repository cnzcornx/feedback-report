Top 5 Issues — เรียงตามความสำคัญ

#1
Bug หลังอัปเดต: Login / Crash / Item ไม่เข้า Inventory
🔴 Critical
Bug 3 รูปแบบ (FB-028 ล็อกอิน Facebook, FB-078 เกมค้าง Story Chapter, FB-179 ของไม่เข้า inventory) กระทบ core loop โดยตรง เป็น "broken promise" ที่เลวร้ายที่สุดในเกม mobile — ผู้เล่นจะไม่รอ แต่จะ uninstall และให้ 1-star review แทน Signal มาจากทั้ง Customer Support และ Store Review พร้อมกัน แสดงว่าปัญหากว้างกว่าที่เห็นในตัวเลข
#2
Pay-to-Win Perception หลังอัปเดต
🔴 High
FB-067 และ FB-112 ตรงกันทั้งคำและความรู้สึก — ผู้เล่นระบุชัดว่า "หลังอัปเดตนี้" ผูกปัญหาเข้ากับ version ล่าสุดโดยตรง กลุ่ม F2P และ Casual Player จะ churn ก่อน ตามด้วย Returning Player ที่เพิ่งกลับมา เมื่อ narrative นี้แพร่ใน Discord / Reddit จะควบคุมยากมาก
#3
Gacha Rate & Pity System ไม่โปร่งใส
🟠 High
FB-001 สะท้อนปัญหาสองชั้น: อัตรา drop รู้สึกต่ำ + ระบบ pity อ่านแล้วไม่เข้าใจ กลุ่ม Whale ยังติงเรื่อง Banner ออกถี่เกิน (FB-214) ซึ่งหมายความว่าปัญหานี้ไม่ได้จำกัดแค่ F2P ความรู้สึก "โรลไปเยอะแล้วไม่ได้" เมื่อรวมกับ pay-to-win perception จะตอกย้ำกัน ส่งผลต่อทั้ง engagement และ revenue
#4
Event Design: Grind สูง, เวลาสั้น, ภารกิจซ้ำ
🟠 High
Event มี feedback มากที่สุด (50 รายการ) และมีทั้งคนชม-คนบ่น ปัญหาหลักคือ stamina ที่ต้องใช้สูง ภารกิจซ้ำ และระยะเวลาสั้น กระทบ Casual Player และคนทำงานอย่างรุนแรง — กลุ่มนี้คือ long-term retention ไม่ใช่ spender หลัก แต่คือคนที่ทำให้ social fabric ของเกมยังมีชีวิต
#5
Auto Battle AI ใช้สกิลผิด ทำให้แพ้ทั้งที่ Power ถึง
🟡 Medium-High
ปรากฏในหลาย Feedback (FB-008, FB-019, FB-051, FB-066 ฯลฯ) จากหลาย segment รวมถึง Guild Leader และ Whale ซึ่งปกติไม่ complain เรื่องเล็กน้อย การที่ auto battle "แพ้ทั้งที่ power ถึง" ทำลายความไว้วางใจในระบบและทำให้รู้สึกต้องจ่ายเงินซื้อตัวแรงกว่าเดิมเพื่อ compensate

Recommended Actions แยกตามทีม

ด่วน24–48 ชม. เร็วๆ นี้1–2 sprint ต่อเนื่องOngoing
🔧 QA
  • ด่วนReproduce และ root cause Bug Login Facebook, Story Chapter crash และ item ไม่เข้า inventory ทั้ง 3 รายการต้องได้คำตอบก่อนส่งต่อ Dev
  • เร็วๆ นี้ทบทวน priority criteria — Bug ที่กระทบ core loop ต้องเป็น P0 โดยอัตโนมัติ ไม่ให้ผ่าน AI เป็น Low
  • ต่อเนื่องเพิ่ม test case สำหรับ auto battle skill priority ทุก patch
🎮 Game Design
  • เร็วๆ นี้ปรับ Event blueprint: ลดภารกิจซ้ำ, เพิ่มระยะเวลา +20%, ทบทวน stamina cost ให้ Casual ทำได้ใน 30 นาที/วัน
  • เร็วๆ นี้Rebalance บอส (one-shot frequency) และตัวละคร PvP ที่ถูกร้อง (Kai, Rex, Luna, Astra, Mika)
  • เร็วๆ นี้เพิ่ม Gold drop rate และลด material requirement สำหรับ F2P
  • ต่อเนื่องออกแบบ New Player Journey ใหม่ — Tutorial แบ่ง phase, ปรับ difficulty curve week 1
📣 Marketing
  • ด่วนชะลอ ad campaign ใหม่จนกว่า Bug หลักจะ fix — ยิง ad ช่วง negative sentiment เสีย budget และเพิ่ม 1-star review
  • เร็วๆ นี้สื่อสาร patch note อย่างโปร่งใส แจ้งว่าแก้อะไรแล้วและขอบคุณที่แจ้งปัญหา
  • เร็วๆ นี้ทดลอง event calendar ล่วงหน้า 2 สัปดาห์ตามที่ผู้เล่นร้องขอ
💬 Community
  • ด่วนPost acknowledgment ใน Discord และ Facebook ว่ารับทราบปัญหา Bug แล้ว กำลัง investigate — ความเงียบคือสัญญาณที่แย่ที่สุด
  • เร็วๆ นี้จัด Q&A หรือ Dev Update ตอบเรื่อง pay-to-win perception และ gacha transparency โดยตรง
  • ต่อเนื่องยกย่อง response time เร็ว (FB-207) เป็น internal benchmark และขยายพฤติกรรมนี้ในทีม
📦 Product
  • ด่วนเพิ่ม category "Monetization" แยกจาก Gacha เพื่อให้วิเคราะห์ pay-to-win, package value, banner frequency แยกกัน
  • เร็วๆ นี้ปรับ AI sentiment model — เพิ่ม rule สำหรับ sarcasm ภาษาไทย ("ถ้าแก้ได้จะดีมาก" = Negative) และ re-validate 300 รายการ
  • เร็วๆ นี้Redesign Pity System UI ให้แสดง progress bar ชัดเจน และเพิ่มหน้าประวัติการเติมเงิน
  • ต่อเนื่องสร้าง feedback loop ปิดวงจร — tag "resolved" และติดตาม sentiment รอบถัดไป

Risk & Things to Watch

⚠️ Risk — ถ้าไม่แก้จะเกิดอะไร

Bug ไม่แก้ใน 72 ชม.

Store rating ลดต่อเนื่อง → App/Play Store algorithm ลดการแสดงผล → organic download หด และ review 1 ดาวหายช้ามาก

Pay-to-Win Narrative ขยายตัว

จะกลายเป็น Reddit/YouTube/TikTok narrative ภายใน 2–3 สัปดาห์ ต้องใช้ PR + compensation package ขนาดใหญ่ดับไฟ ซึ่งแพงกว่า rebalance ตั้งแต่ต้นหลายเท่า

Event Design ไม่ปรับ

Casual Player login น้อยลง → DAU ลด → social fabric บางลง → Whale ที่เล่นเพื่อ community ได้รับกระทบในระยะกลาง

New Player Experience แย่ต่อเนื่อง

D1/D7 retention ต่ำ → ต้นทุน UA สูงขึ้นเรื่อยๆ เพราะต้องหาคนใหม่มาแทนที่คนที่หลุดออก

👁️ Things to Watch — สิ่งที่ต้องติดตาม
  • 📊Negative Sentiment รอบถัดไป (มิ.ย. 2026) — ติดตามว่าลดลงต่ำกว่า 40% ได้หรือไม่หลัง patch fix Bug ถ้ายังเกิน 45% แสดงว่ามีปัญหาเชิงระบบที่ยังไม่ถูกระบุ
  • 💎Whale Churn Signal — ถ้า Whale ให้ feedback เชิงลบเพิ่มขึ้นใน banner ถัดไป ให้ถือเป็น early warning ของ revenue drop เดือนถัดไป ควร monitor ควบคู่กับ ARPPU
  • 📱Pay-to-Win Narrative ใน External Channels — monitor Reddit, YouTube และ TikTok keyword ทุกสัปดาห์ ถ้า organic content เพิ่มขึ้นให้ escalate ทันที
  • 📈New Player Retention (D7/D30) — เปรียบเทียบ D7 retention เดือนนี้กับก่อน update ถ้าลดลง >5% ให้ prioritize New Player Journey ขึ้นเป็นอันดับ 1
  • 🤖Auto Battle หลัง Patch — หลัง fix แล้ว เก็บ feedback รอบถัดไปยืนยันว่าปัญหาหายจริง เนื่องจาก pattern นี้กระจายในหลาย segment และหลาย version

Workflow & Prompt Log

รายงานนี้จัดทำโดยใช้กระบวนการ AI-Assisted Analysis ร่วมกับ Human Review เพื่อให้ได้ผลลัพธ์ที่แม่นยำและนำไปใช้ได้จริง

1

รวบรวม Feedback และจัดทำ Dataset

รวบรวม Feedback จาก 8 ช่องทาง (App Store, Play Store, Discord, Customer Support, Community Post, In-game Survey, Facebook, Google Form) จำนวน 300 รายการ ในช่วง 2–23 พ.ค. 2026 บันทึกเป็นไฟล์ player_feedback_300_dataset.xlsx พร้อมข้อมูล metadata ครบถ้วน

2

AI Classification ด้วย Claude

ส่งไฟล์ Excel ให้ Claude อ่านและ classify อัตโนมัติ โดย Prompt กำหนด Schema ชัดเจน: sentiment (Positive/Neutral/Negative), category (9 ประเภท), priority (High/Medium/Low), ai_summary (สรุป ≤15 คำภาษาไทย) และ suggested_owner (ทีมที่รับผิดชอบ) — ผลลัพธ์บันทึกเป็น feedback_analysis_300.xlsx

3

Merge ไฟล์และ Human Review

Merge ทั้ง 2 ไฟล์เข้าด้วยกันโดยใช้ feedback_id เป็น key สร้างไฟล์ feedback_final.xlsx จากนั้น Human Review ทั้ง 300 รายการ พบ error 32 รายการ (10.7%) โดยมีสาเหตุหลัก 3 ประการ:

  • AI อ่านประโยคลงท้าย "ถ้าแก้ได้จะดีมาก" แล้วจัด Sentiment เป็น Positive ผิด
  • จัด Gacha แทน Reward สำหรับ feedback เรื่องรางวัล login และราคา item
  • Bug บางรายการได้ priority ต่ำเกินไป และขาด category Monetization
