Key Insights & Findings
🔴 Critical — High Priority
Bug: Lag / Frame Drop ในด่านบอสใหม่
พบ 9 รายการซ้ำกันจากหลาย Platform (PC Emulator, Android, iOS) — เกม lag และ frame drop จนผู้เล่นกดหลบ skill บอสไม่ทัน ส่งผลกระทบต่อ gameplay โดยตรง → Dev Team ต้องแก้ด่วนใน Sprint นี้
🔴 Critical — High Priority
Bug: Facebook Login ขัดข้อง
ผู้เล่นอย่างน้อย 2 รายยืนยันว่าล็อกอินด้วยบัญชี Facebook ไม่ได้ตั้งแต่เมื่อวาน กระทบต่อ Retention และการเข้าถึงบัญชี → Dev Team แก้ด่วน
🟠 Important — Balance/Combat (85 รายการ, 17 Negative)
ตัวละคร/บอส Balance ไม่สมดุล
บอสใหม่ใช้สกิล One-shot บ่อยเกินไป, ตัวสาย Heal อ่อนเกินเทียบ Boss damage, Meta PvP แคบลง — ควรออก Balance Patch โดย Game Design Team
🟠 Important — Event & Quest (81 รายการ, 16 Negative)
Event ภารกิจซ้ำ + แต้มไม่พอแลกของหลัก
ผู้เล่นชื่นชอบธีม Event แต่ Mission ซ้ำกันมากและ Point Economy ไม่เอื้อให้ Casual Player แลกของหลักได้ — Event Team ควรปรับ Economy
🟡 Medium — Monetization
Login Reward ดูธรรมดา + Gacha Rate ไม่โปร่งใส
5 รายการต้องการเพชร/Ticket เพิ่มใน Daily Login, 13 รายการรู้สึกท้อหลัง Pull หลายสิบครั้งไม่ได้ตัว — พิจารณา Pity System และปรับ Login Reward Table
🟢 Positive — ต่อยอดได้
ดีไซน์ตัวละครใหม่และธีม Event ได้รับคำชม
ผู้เล่นหลายกลุ่มชื่นชมดีไซน์ตัวละครใหม่และธีม Event ว่าสวยและสนุก ทิศทาง Art และ Event Design ปัจจุบันตรงใจ Target Audience — ควรรักษาและต่อยอด
📊 Platform Insight
PC Emulator = ฐาน Feedback ใหญ่สุด (39.7%)
119 จาก 300 รายการมาจาก PC Emulator — ควร Optimize Performance บน Emulator เป็นพิเศษ โดยเฉพาะ Lag ในด่าน Boss ที่เป็น Critical Bug อยู่แล้ว
📊 Segment Insight
Guild Leader & F2P มี Negative Rate สูงสุด (~28%)
สองกลุ่มนี้ Negative Rate สูงกว่ากลุ่มอื่น — Guild Leader เน้น Balance/Meta, F2P เน้น Progression/Economy — ควรจัดลำดับการแก้ไขให้ครอบคลุมทั้งสองกลุ่ม
Recommendations — เรียงตามลำดับความสำคัญ
1
🔴 ระยะสั้น (Sprint ปัจจุบัน) — แก้ Bug ด่วน แก้ไข Bug Lag/Frame Drop ในด่านบอสใหม่ และ Facebook Login ขัดข้องโดยด่วน เพื่อลดผลกระทบต่อ Retention และประสบการณ์การเล่นโดยตรง Dev Team
2
🟠 ระยะกลาง Sprint 1 — Balance Patch ลด Frequency การใช้ One-shot ของบอสใหม่, เพิ่ม Stat ตัวสาย Heal, เพิ่ม Meta Diversity ใน PvP เพื่อลด 17 Negative ใน Balance/Combat Game Design Team
3
🟠 ระยะกลาง Sprint 1 — Event Economy เพิ่มความหลากหลายของ Mission ใน Event, ปรับ Point Requirement ให้ Casual Player สามารถแลกของหลักได้จริง Event Team
4
🟠 ระยะกลาง Sprint 2 — Monetization เพิ่ม Pity System หรือ Soft Pity ใน Gacha, ปรับ Daily Login Reward ให้มีเพชรหรือ Ticket เพิ่มเพื่อดึงดูดและรักษา Returning Player Monetization Team
5
🟢 ระยะยาว — Roadmap Optimize Performance บน PC Emulator (39.7% ของ Feedback Base) และต่อยอดทิศทาง Art/Event Design ที่ได้รับ Positive Feedback เพื่อรักษาฐานผู้เล่น Dev Team + Content Team
